## Общий обзор

Данный репозиторий - студенческий научный проект, на стыке истории и программирования. Задача - реализовать комфортное, компактное и карманное веб-приложение для туристов, иностранных гостей позволяющее познакомиться с южноуральским мегаполисом Челябинском.

Веб-приложение было реализовано на [React](https://github.com/react/react) со связкой [TypeScript](https://github.com/microsoft/typescript). В качестве интерактивной карты используется [MapLibre GL](https://github.com/maplibre/maplibre-gl-js), а покрывается тестами благодаря [Jest](https://github.com/jestjs/jest) и [Playwright](https://github.com/microsoft/playwright).

Поэтому важно помнить: код в проекте может быть неэффективным и местами не безопасным. Код писали студенты, которые не имеют коммерческого опыта.
