# Стиль написания кода

Чтобы код был легко поддерживать, было принято решение писать код в едином стиле. Для удобства, в проекте используется утилита [Prettier](https://github.com/prettier/prettier).

Чтобы запустить форматирование, используйте команду:

```bash
npm run format
```

В проекте также используется инструмент для статистического анализа кода [ESLint](https://github.com/eslint/eslint).

Для запуска статистического анализатора кода, используйте команду:

```bash
npm run lint
```

`ESLint` имеет возможность исправлять небольшие ошибки:

```bash
npm run lint:fix
```
